# ☕ Coffee Ordering App

A simple **Coffee Ordering Desktop Application** built using **Python and Tkinter**.
The application provides an interactive graphical interface where users can browse coffee items, add them to their order, remove items, clear the order, calculate the total price, and complete checkout.

## 📌 About the Project

The **Coffee Ordering App** is a beginner-friendly Python GUI project designed to demonstrate the use of:

* Python Object-Oriented Programming
* Tkinter GUI development
* Event-driven programming
* Lists and dictionaries
* Dynamic price calculation
* Message boxes and user interactions

The application contains a coffee menu with multiple items such as Espresso, Latte, Cappuccino, Americano, Mocha, Macchiato, Frappuccino, and Black Coffee.

## ✨ Features

* ☕ Browse available coffee items
* ➕ Add coffee items to the order
* 🗑️ Remove selected items
* 🧹 Clear the complete order
* 🔢 Automatically calculate item quantities
* 💰 Automatically calculate the total price
* 🛒 Checkout confirmation
* 📋 Display order summary
* ⚠️ Validation for empty orders
* 🖥️ Simple and user-friendly desktop GUI

## 🛠️ Technologies Used

* **Python 3**
* **Tkinter**
* **OOP (Object-Oriented Programming)**

## 🚀 How to Run

### 1. Clone the Repository



```bash
python coffee_shop.py
```

The Tkinter window will open automatically.
